## Observation
The frontend rule and the story AC both assume "Vite's React-TS template scaffolds ESLint config"
and pin React 18, but the current scaffolder (create-vite 9.x) now defaults to React 19, oxlint
(not ESLint, with a .oxlintrc.json and "lint": "oxlint"), Vite 8, and a TS 6 beta tsconfig using
options like erasableSyntaxOnly. So `npm create vite -- --template react-ts` no longer produces the
toolchain the rule describes; the coder had to pin React 18 + ESLint + Vite 5 by hand to satisfy the
rule/AC. The rule's parenthetical about ESLint being template-owned is now stale.
